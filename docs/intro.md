# Proyecto "TaskFlow"

Bienvenido a la documentación oficial del proyecto **TaskFlow**, una aplicación web ficticia de gestión de tareas colaborativas desarrollada como caso de estudio para demostrar un flujo completo de ingeniería de software.

## Descripción general

**TaskFlow** permite a equipos pequeños organizar tareas, asignar responsables y hacer seguimiento del progreso mediante tableros Kanban. El proyecto se ha desarrollado siguiendo un ciclo de vida clásico:

1. **Análisis de requisitos**
2. **Diseño del sistema**
3. **Implementación**
4. **Pruebas**
5. **Despliegue**

## Objetivos de la documentación

Esta documentación tiene como finalidad:

- Servir como guía reproducible para estudiantes y desarrolladores.
- Documentar las decisiones técnicas tomadas en cada fase.
- Facilitar el mantenimiento y la extensión futura del sistema.

## Estructura de la documentación

| Sección | Contenido |
|---------|-----------|
| Análisis | Requisitos funcionales y no funcionales |
| Diseño | Diagramas UML y arquitectura |
| Implementación | Estructura del código y tecnologías |
| Pruebas | Estrategias de testing y análisis |
| Despliegue | Publicación en GitHub Pages |

## Tecnologías utilizadas

- **Frontend:** React + TypeScript
- **Backend:** Node.js + Express
- **Base de datos:** PostgreSQL
- **Documentación:** Docusaurus v3
- **CI/CD:** GitHub Actions

> **Nota:** TaskFlow es un proyecto ficticio creado exclusivamente con fines educativos y de documentación.
